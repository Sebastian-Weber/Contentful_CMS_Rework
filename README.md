An API directory app built around a headless CMS, developed as a group project during the WBS Coding School bootcamp.

## What This Is

The team built a custom collection of APIs, hosted via Contentful, then migrated the data into a JSON file processed by an Express server. My focus was the frontend: an off-canvas sidebar, a detail page, pagination, a slider carousel, and search/filter functionality built with DaisyUI.

## Tech Stack

| Layer | Tool |
|---|---|
| Frontend | React, DaisyUI |
| Backend | Express.js |
| CMS | Contentful (headless) |
| Data | Custom JSON |

## My Role

Frontend development: UI, navigation, detail views, pagination, search and filtering.

## Context

Group project, WBS Coding School, 2024. Focus on working with a headless CMS and a backend server in a team setting.
